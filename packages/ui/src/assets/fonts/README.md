# Pretendard

Pretendard Variable 1.3.9, from the official `pretendard` npm package:
https://unpkg.com/pretendard@1.3.9/dist/web/variable/woff2/PretendardVariable.woff2

Project: https://github.com/orioncactus/pretendard
License: SIL Open Font License 1.1, copied to `public/licenses/Pretendard-OFL.txt`
and included in the built UI.

The font is bundled by Vite so dev, packaged, and static workbenches can load it
without a CDN. The UI sans-serif stack uses Pretendard; the code panel keeps its
monospace stack and Typst documents use their own font configuration.
