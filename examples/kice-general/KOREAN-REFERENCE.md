# 국어 평가원 원본과 컴포넌트 확장

비교일: 2026-10-08. 아래의 **원본 관찰**은 내려받은 PDF의 텍스트 객체·선분과 실제 PNG를 함께 확인한 결과다.
**구현 목표**는 그 관찰을 재사용 가능한 Typst API로 옮긴 것이며, 원본의 모든 글리프·좌표가 픽셀 단위로 같다는 뜻은 아니다.
원본 문제·문학 작품의 본문은 fixture나 story에 복제하지 않는다. 예시는 마인크래프트 배경의 창작 자료를 사용한다.

## 원본 관찰: 판면과 서체

좌표는 왼쪽 위 원점의 원본 pt이다. 선분은 잉크 외곽이 아닌 중심 좌표다.
원본의 subset 폰트명을 CP949로 해독했으며, 다음 서체 구분은 육안으로 추정한 굵기가 아니다.

| 요소 | 원본에서 읽은 값 | 공용 글꼴·크기 관리의 대응 |
| --- | --- | --- |
| 전체 단 지문 프레임 | 왼쪽 x87.90…405.36, 폭317.46pt; 선0.36pt | `korean-layout.stroke`, `frame-x` |
| 지문 안쪽 시작 | x96.42, 프레임에서8.52pt | `korean-layout.frame-x` |
| 산문 첫 줄 | x106.68, 본문 시작에서10.26pt | 국어 프로필의 문단 들여쓰기 |
| 묶음 안내 | `*신명-태고딕`11.5pt; 계속 쪽 metric top159.02pt | `korean-instruction`, `sizes.body` |
| (가)/(나) 지문 라벨 | `*한양견명조`11.5pt | `korean-section`, `sizes.body` |
| 지문·발화·보기 내부 | `*신명-중명조`11.5pt, 실제 장평95% | `body`/`material`, `SM JMyungJo Std` |
| 평문·운문 행간 | 기준선 간격18.36–18.42pt | 국어 프로필의 `material-leading` |
| 작품 출처 | 중명조11pt, 오른쪽 끝396.88/745.48pt | `body`, `sizes.korean-source` |
| 어휘 풀이 | 중명조10.5pt; 표본 두 행 간격15.72pt | `body`, `sizes.korean-note` |
| 면접·학생 대화 화자 | `*신명-태고딕`10.5pt | `korean-speaker`, `sizes.korean-speaker` |
| 2018년 희곡 화자 | `*신명-태고딕`11.5pt | 같은 역할의 가족, `speaker-size:`로 크기 조절 |
| 매체 자료의 글자 | UI와 라벨은 고딕, 지문 설명은 명조 | 인터페이스 라벨 역할과 `body`를 구분 |

`fonts.typ`의 전용 역할 `korean-instruction`·`korean-speaker`는 `SM TGothic Std`,
`korean-section`은 `SM KMyungJo Std`이다. 자료 제목·매체 인터페이스의 `directive`는 `SM JGothic Std`를 사용한다.
가족명을 컴포넌트에 직접 선언하지 않고 중앙 역할을 선택한다.
안내·지문 라벨의 크기는 `sizes.body`/`sizes.print-body`, 화자는 `sizes.korean-speaker`/`sizes.print-korean-speaker`에서 관리한다.
원본의 한양 견명조와 포함된 SM 견명조는 다른 파일이므로 라벨의 완전한 글리프 일치를 주장하지 않는다.
A4 전용 값은 `sizes.print-korean-source`·`print-korean-note`·`print-korean-media` 등에서 독립 관리한다.
원본 11/10.5pt를 축소판의 실제 글자 크기로 오해하지 않는다.

**대화 내어쓰기:** 2026년 면접 표본은 화자 x96.42, 후속 줄 x115.38으로 **18.96pt** 차이다.
화자 길이가 달라도 후속 줄은 이 기준을 따른다. 2018년 희곡은 후속 줄이10.32pt 안쪽으로 들어간다.
전체 화자 중 가장 긴 폭에 정렬하는 자동값은 읽기 편한 구현 선택이며 원본 실측값 자체는 아니다.
`speaker-width:`는 첫 줄의 화자 칸, `hanging-indent:`는 후속 줄의 시작 위치를 독립적으로 정한다.
`speaker-width: none`은 화자 뒤에 발화를 바로 이어 쓰며, `speaker-size:`·`gap:`도 원고별로 지정할 수 있다.

**연속 프레임:** 2026년 2쪽과 2018년 8–9쪽은 처음에만 윗선, 끝에만 아랫선이 있다.
중간 단·쪽의 시작과 끝에는 좌우 선만 이어지며, 각 fragment가 별도 사각형처럼 닫히지 않는다.
따라서 긴 지문을 문항용 `material`의 분할 방지 상자로 감싸지 않는다.

**문학과 주석:** 운문의 행·연과 산문시의 문단은 서로 다르다. 산문시는 단폭에 맞춰 자연스럽게 줄바꿈한다.
작품 출처와 어휘 풀이는 모두 명조이며 지문 프레임 안에 남는다. 어휘 풀이를 페이지 하단의 native footnote로 보내지 않는다.
보기 내부도 같은 명조 원칙이다. 화자·자료 제목·인터페이스의 고딕과 본문 명조를 구별한다.

## 구현 목표와 컴포넌트 대응

기존 `passage`, `material`, `view`, `data-table`, `u`, `mark`는 계속 사용할 수 있다.
새 API는 아래 구조를 조합하도록 확장하며, 임의의 원본 문항을 그대로 전사하는 파서는 아니다.

| API | 원본 형식에서 가져온 목표 |
| --- | --- |
| `instruction` | 문항 범위와 1–3줄 안내, 다음 자료와 함께 유지 |
| `passage-heading` | (가)/(나) 등 견명조 역할의 지문 라벨, 뒤 본문과 함께 유지 |
| `framed-passage` | 긴 지문을 자연 분할하고 시작·끝 cap만 표시 |
| `passage-sections` | 임의 개수의 (가)/(나)/(다)와 본문 형식을 하나의 프레임에 조합 |
| `paired-passage` | (가)/(나) 라벨과 프레임을 포함하는 두 지문 인터페이스 |
| `verse` | 행·연 보존, 양끝 정렬 해제, 긴 행의 내어쓰기와 짧은 연의 분할 방지 |
| `source-line` | 오른쪽 명조 출처, 제목의 `「 」` 자동 부착 |
| `passage-notes` | 지문 안의 작은 명조 어휘 풀이와 내어쓰기 |
| `excerpt-gap` | 본문 중간의 생략 표시와 중앙 정렬 |
| `marked-range` | [A] 등 범위를 왼쪽/오른쪽에 표시, 본문과 겹치지 않게 폭 확보 |
| `synopsis` | 소설 발췌 앞의 줄거리 라벨과 설명 문단 |
| `dialogue` | 화자와 발화의 기준선, 화자 칸과 후속 줄 들여쓰기·크기·간격의 독립 조절 |
| `stage-direction` | 화자 없는 독립 지시문과 앞뒤 문단 간격 |
| `draft` | 초고·작성문 자료의 제목과 프레임 |
| `editor-note` | 수정 지시·메모 라벨과 이어지는 명조 설명 |
| `writing-plan` | 1–4단계 개요, 단폭에 따른 가로/세로 자동 배치와 명시 방향 |
| `media-window` | 제목·도구 영역·자료 본문을 가진 흑백 화면 패널 |
| `media-post` | 작성자·시간·본문을 가진 게시글/댓글 단위 |
| `reading-set` | 안내·자료·문항을 같은 흐름에서 작성하되 문항 전체는 유지 |
| `quotation` | 보기 내부에 들어가는 별도의 명조 인용 상자 |

`passage-sections`·`paired-passage`에는 프레임이 포함되어 있으므로 `framed-passage`로 다시 감싸지 않는다.
`source-line`에는 `「 」` 없는 제목을 전달한다. `reading-set`은 자료 뒤의 남은 공간부터 문항을 자연스럽게 이어 놓는다.
`quotation`은 `view` 내부에 조합하고 인용문 전체를 유지하므로 짧은 인용 자료에 사용한다.

`verse`·`marked-range`의 기본 `auto`는 짧은 연·범위를 함께 유지하고 긴 내용은 단·쪽에서 나눈다.
`keep-stanzas:`·`keep:`로 이 정책을 조절한다. 짧은 `marked-range`는 실제 본문 높이의 중앙에 라벨을 놓는다.
큰 범위의 라벨을 최초 fragment에 두는 정책은 구현 선택이다.
중앙 라벨을 무조건 분할 전 전체 높이에 고정하면 첫 fragment 밖으로 밀려날 수 있으므로 피한다.
표·수식·이미지는 해당 기존 컴포넌트를 새 지문이나 자료 안에서 그대로 조합한다.
키 큰 수식에는 기존 `display`와 높이 보정을 적용한다.

지문과 범위의 기하는 `korean-layout`, 대화·초고·개요·화면은 `korean-material-layout`,
보기 제목과 내부 인용은 `korean-view-title`·`quotation-layout`에 모았다.
`korean-reference-geometry`의 정밀 머리말·중앙선·쪽번호 보정은 원본과 A4 축소판에 적용한다.
실제 A4 전용판은 `print-geometry`와 인쇄용 크기를 사용하여 읽기 편한 자연 조판을 유지한다.

## 검증해야 할 경계와 남는 범위

- 두 단·여러 쪽 지문: 중간 가로선이 생기지 않고 마지막 cap이 본문과 떨어지지 않는지 확인한다.
- 지문 라벨·출처·풀이: 라벨만 단 끝에 남거나 작품 출처·어휘 풀이가 무관한 다음 자료처럼 보이지 않게 한다.
- 운문: 행·연을 유지하면서 A4의 긴 행을 자연스럽게 넘기고 후속 줄을 구별한다.
- 범위 표지: 양쪽·한 행·여러 문단·단 경계에서 라벨과 텍스트의 충돌을 확인한다.
- 대화: 서로 다른 화자 길이, 여러 줄 발화, 지시문, 밑줄·인라인 표지를 함께 확인한다.
- 자료 패널: 본문·표·그림을 실제 단폭에 놓고 A4와 원본 판형에서 넘침을 확인한다.

복잡한 브라우저·휴대전화 외곽, 중첩 댓글 연결선, 실제 서비스 아이콘과 팸플릿 전체 도안은 현재 공용 패널의 목표 범위보다 넓다.
매체 패널은 이런 구조의 작성 출발점이며 모든 원본 화면을 자동으로 재현하지 않는다.
매우 긴 화면은 원고에서 읽을 수 있는 자료 단위로 분리해야 하며, 분할 방지 패널을 한 쪽 높이 이상으로 채우지 않는다.
중세국어의 옛한글 전용 서체·복잡한 음운 도식·시나리오의 숏 번호 등은 별도 확장 대상이다.

최종 검증은 41개 story·66개 SVG snapshot과 국어 35개 PDF/52쪽을 확인했다.
국어 창작 문제지는 원본 3쪽/A4 4쪽이고, 같은 설정의 story와 직접 PDF는 픽셀 차이가 없었다.
