# 2026학년도 6월 국어 1쪽 픽셀 보정

2026-10-08에 **2026학년도 6월 모의평가 국어 PDF 1쪽**을 고정 기준으로 삼았다.
[원본 파일](https://www.haksi.kr/api/mock-exams/file?id=2026-06-g3-korean-exam)은 평가원 문서의 공개 미러다.
MediaBox는 842×1191pt, 원본 SHA256은
`004dfd2cd12ffe07e10410c7ae15406abf7cf9a7b5952d672fbf143b1e549b58`이다.

`korean-pixel.typ`은 같은 위치의 머리말, 31행 지문, 3문항, 보기 안 인용문·대화,
선지를 마인크래프트 창작 원고로 배치한다. 원본 문제와 문학 작품의 본문은 복제하지 않았다.
쪽번호의 전체 20은 원본 표지를 대조하기 위한 값이며, 이 기준판의 실제 분량은 **1쪽**이다.
하단 문구는 비공식 창작 예시임을 밝힌다.

## 측정 방법

원본과 후보를 **같은 PDFium으로 300dpi** 렌더했다. 1px=0.24pt다.
검은 잉크는 RGB 최솟값이128 미만인 픽셀로 정의하며, 리사이즈나 자동 정렬 없이
같은 페이지 좌표의 라벨·선만 비교한다. IoU는 두 잉크 집합의 교집합/합집합이다.
본문은 서로 다른 문장이므로 페이지 전체 픽셀 일치율을 계산하지 않고 기준선·들여쓰기를 비교한다.
PDF 좌표와 실제 잉크 외곽은 서체의 metric 때문에 다를 수 있어 따로 기록한다.

전체 수치는 [calibration/korean-2026-june-p1.json](calibration/korean-2026-june-p1.json)에 있다.
검증한 후보 SHA256은
`1c427646c4eabb2ed3e6097f8b8b774e8d6b631608026042cec684cc848b7349`이다.

| 영역명·교시 테두리·큰 쪽번호 | 검은 잉크 외곽의 네 변 오차0px |
| 시험명·하단 쪽수 상자 | 검은 잉크 외곽 최대1px 차이 |

원본의 행간은18.36/18.42pt의 반올림 주기를 가진다. 후보의18.38pt 균등 간격에서 생기는
기준선 차이는 위의0.172px 안에 있다. 행마다 임의 위치를 넣어 일반 원고의 흐름을 깨지는 않았다.

안내와 보기 제목은 처음에 기준선 좌표를 맞춘 뒤 실제 잉크를 위로0.48pt 이동했다.
안내 본문 IoU가0.4675→0.8885, 범위 표지가0.5395→0.7027,
보기 제목이0.3173→0.4948로 개선됐다. 따라서 이 두 라벨의 PDF 기준선은
원본보다0.48pt 높다. 픽셀 위치 보정과 기준선 일치를 동시에 주장하지 않는다.

## 컴포넌트와 고정 기준판의 구분

- `theme.typ`의 `korean-reference-geometry`: 교시 테두리·영역명·큰 쪽번호·중앙선·하단 상자.
- `typography.typ`·`question.typ`: 발문11.48pt, 번호13pt, 발문 시작·후속 줄·선지 내어쓰기.
- `korean-layout`: 안내의 글자 advance·간격과 프레임 여백·선.
- `korean-view-title`·`quotation-layout`: 보기 제목 위치와 안쪽 인용 상자의 여백·윗선 두께.
- 모든 글꼴 가족과 역할별 크기는 `fonts.typ`에서 관리한다.

일반 `framed-passage`는 `height: auto`로 긴 지문을 단·쪽에서 자연 분할하며,
중간에는 좌우 테두리만 이어진다. 고정 기준판은 `height: 581.1pt`를 지정해
원본과 같은 stroke 경로로 세로선을 그린다. 고정 높이는 분할 방지이며 원고가 안에 들어가야 한다.
원본의 보기 왼쪽 선을 두 번 그리는 특성도 이 기준판에만 반영한다.
이러한 원본 출력의 세부 특성을 일반 보기 전체에 강제하지 않는다.

`fixtures/korean-pixel.typ`의 고정 좌표는 `suneung`과 `a4-scaled`에서 같은 비율로 변한다.
원본과 축소판을 같은 시각적 크기로 확대해 조판을 확인했다.
읽기 크기의 A4 전용판은 `korean-sample.typ`의 자연스러운 흐름을 사용하며
원본 고정 좌표와 독립적으로 조판한다.

## 남는 차이

원본 ‘국어 영역’은 비트맵이고 후보는 편집 가능한 글자다. 외곽은 맞지만 내부 IoU는0.7787이다.
원본의 한양 견명조·subset SM 서체와 포함한 SM 파일의 윤곽·hinting도 완전히 같지 않다.
교시·보기 제목·문항 번호·원문자 등의 잉크 차이가 남으며, 이 결과를 **페이지 전체 픽셀 동일**이라고 부르지 않는다.
서체의 윤곽 차이를 숨기기 위해 원본의 글자 이미지를 붙이지 않았다.

## 다시 실행

```sh
node examples/kice-general/workbench.mjs pdf:korean:pixel --ignore-system-fonts
python3 examples/kice-general/scripts/audit-korean-pixel.py \
  /path/to/2026-june-korean.pdf \
  examples/kice-general/dist/korean-pixel.pdf \
  /tmp/kice-pixel-audit --dpi 300
```

측정기는 `pdfplumber`, `pypdfium2`, `numpy`, `Pillow`를 사용한다.
`metrics.json`, 비교 표, 공통 라벨과 테두리만 남긴 overlay, 창작 후보의 미리보기를 생성한다.
청록은 원본에만 있는 잉크, 자홍은 후보에만 있는 잉크, 짙은 회색은 겹치는 잉크다.
원본의 본문 텍스트나 전체 페이지 이미지를 출력 보고서에 저장하지 않는다.

국어 컴포넌트는 별도로 35개 PDF/52쪽의 원본·A4·경계를 확인했다.
41개 story/66개 SVG snapshot이 통과하며 기존 수학·과학·해설 출력은 유지한다.
